# 🏆 eSports Championship Manager

## 📌 Sobre o projeto

O eSports Championship Manager é um projeto de banco de dados desenvolvido para a disciplina de Linguagem SQL.

O sistema tem como objetivo realizar o gerenciamento de campeonatos de eSports, permitindo a organização de informações relacionadas a campeonatos, equipes, jogadores, partidas, resultados e demais elementos envolvidos na realização das competições.

O projeto será desenvolvido utilizando SQL e PostgreSQL, com o apoio da ferramenta DBeaver.

---

## 🎯 Objetivo

Desenvolver um banco de dados relacional capaz de organizar e gerenciar as principais informações de campeonatos de eSports, aplicando conceitos de modelagem de dados, relacionamentos, integridade e consultas SQL.

---

## 🧠 Escopo inicial

O sistema poderá contemplar:

- Cadastro de jogadores
- Cadastro de equipes
- Cadastro de campeonatos
- Cadastro de modalidades/jogos
- Organização de partidas
- Registro de resultados
- Controle de participantes
- Registro de estatísticas
- Consultas e relatórios

> O escopo poderá ser atualizado e expandido durante o desenvolvimento do projeto.
